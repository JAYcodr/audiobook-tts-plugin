# 截图

四张控制台实拍，来自作者自己的机器（Mac mini M4，混合引擎在跑）：

| 文件 | 页面 | 看什么 |
|---|---|---|
| `shot-live.png` | 时间线 | 走带按钮、RUN/本地/云端/混合灯、节目带（每段宽度 = 音频秒数）、段内缝 = 分段数 |
| `shot-config.png` | 渲染设置 | 六个模块：引擎 / 本地引擎 / 音色 / 合成与缓存 / 传输 / 鉴权 |
| `shot-record.png` | 工程史 | 压缩日带（一天一格，宽度 = 当日合成音频秒数）、延迟分位、CSV 导出 |
| `shot-access.png` | 交付 | 导入地址、朗读 URL、METHOD/BODY、令牌、curl 试一句、错误码 |

截图里的数值、端口、地址都是作者环境的，**别照抄**——按你自己机器上显示的去填。

那部分是 28 MB 的设计过程文件，对装机没用。想看的话去原仓库。
